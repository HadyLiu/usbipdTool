# 使用说明

当前版本：**0.1.2**。UsbipdTool 只是 usbipd-win 的图形界面封装，**不会附带或自动安装 usbipd**。请先在 Windows 上单独安装 [usbipd-win](https://github.com/dorssel/usbipd-win) 并启用 WSL 2，再运行本程序。

## 运行前提

- Windows，已安装 usbipd-win 和 WSL 2。
- 以管理员身份运行 `dist/UsbipdTool.exe`（程序内嵌 `requireAdministrator` 清单，启动时会弹出 UAC）。
- 未检测到 `usbipd` 时，程序会提示安装（例如 `winget install usbipd-win`），确认后退出。安装完成后再重新打开本程序。

## 主界面

窗口顶部显示 usbipd 版本、管理员权限和程序版本。中间是设备表格（BUSID、VID:PID、设备、状态、操作）：BUSID 与 VID:PID 为更紧凑的固定宽度，从而把设备列的起点向左推移，挤出的宽度分给设备名和状态列（状态列需能完整显示常见的「已附加」+ IPv4 + [auto] 文案）；操作列宽度固定为可容纳两个按钮。列宽只随窗口宽度变化，不随当前设备文字或绑定等状态变化。默认窗口（约 1024 物理像素，含 150% 缩放、约 600–670 逻辑像素客户区）下表格应落在可视区域内，不出现横向滚动；过窄时名称或状态可以省略号截断，但不会把内容藏到滚动条后面。表头与每行的文字、状态和操作按钮按实际绘制范围在固定行高内水平和垂直居中，同一行共用中线；名称、状态或过长的编号会截断，鼠标悬停可查看全文。列表按 BUSID 数值从大到小排列。默认窗口约为 1024×760 物理像素（可缩放）；宽度和高度都不能小于该默认尺寸（按 DPI 和窗口边框换算为逻辑客户区，例如 150% 缩放时客户区约 667×468），但可以向右或向下增大。页首为图标、名称和版本/权限信息，工具栏在其下始终按内容紧凑单行排列（控件用自然宽度，分组间距 8 个逻辑像素，不下拉框和按钮被拉成等宽格）；在默认窗口（含 150% 缩放、客户区约 640–670 逻辑像素）下应完整显示全部六项，无需横向滚动。仅在窗口确实过窄时才出现横向滚动，不换行。没有顶部统计数字区。空闲时不保留底部状态栏，底部面板标题为「日志」，默认高度约为原先对半分割时的一半，让出的空间给设备表格，并仍贴到距窗口下沿约 8 个逻辑像素；扫描、无设备或忙碌时的提示放在页首信息行右侧预留的紧凑区域内，不占用表格高度。

工具栏从左到右为「语言」「主题」「重新扫描」「强制绑定」「过滤规则」和「设置」，垂直居中、按内容收缩，不为六项均分整行宽度。下拉框宽度随选项文字变化。仅在窗口确实过窄时才横向滚动。

插拔 USB 设备时会自动刷新列表。正在执行绑定等操作时，插拔事件会排队，待当前操作结束后再扫一次。「重新扫描」仍可手动触发。

## 设备操作

按设备当前状态显示按钮：

| 状态 | 可执行的操作 |
|------|----------------|
| 未共享 | 绑定（若勾选「强制绑定」，命令会追加 `--force`） |
| 已共享 | 附加、解绑 |
| 已附加 | 分离、解绑 |

- **绑定**：执行 `usbipd bind --busid <id>`。若因 USBPcap / hrdevmon 过滤器冲突失败，会询问是否用 `--force` 重试。工具栏「强制绑定」只影响下一次绑定。
- **附加**：不再弹出对话框，立即按「设置」里已保存的偏好执行 `usbipd attach --wsl [发行版] --busid <id> [--host-ip <ip>] [--auto-attach]`。不会等待 WSL 发行版列表加载。若未使用默认发行版却未填写发行版，或主机 IP 填写了但不是合法的 IPv4/IPv6，会提示错误并且不会执行附加。
- **分离 / 解绑**：点击后直接执行，不再弹出确认框。若该设备正在由 `--auto-attach` 常驻进程看管，分离或解绑前会先结束该进程（否则设备可能被立刻重新附加）。成功的分离会把该设备记住为「已共享」（重插后最多恢复绑定，不会再自动附加）；成功的解绑记住为「未共享」（重插后不自动绑定或附加）。失败的命令不会改写这份记忆。关闭程序时会结束这些后台进程，但会保留记忆，以便下次启动时恢复。

命令在后台线程执行，不弹出黑色控制台窗口；实际命令和输出会写入日志面板。

关于自动恢复：本程序会为每台**已成功操作过**的设备记住目标状态（未共享 / 已共享 / 已附加），身份优先使用 `usbipd state` 中的 PersistedGuid 和 InstanceId，不用 BUSID（总线号会变，也可能被别的设备占用），也不会在多台相同 VID:PID 之间猜测。拔出设备时不会把「已附加」记忆改成不在线。程序启动或检测到重插后，只对已记录的设备做非强制绑定和（若目标是已附加）带 `--auto-attach` 的附加；不会把其它外设统统绑定。设备须能被本程序扫描到，因此**需要本程序正在运行**；本程序不会自行安装系统服务或开机自启。`--auto-attach` 参数会让 usbipd 进程在本程序运行期间常驻，输出写入日志；退出程序时结束该进程，记忆仍保留。

## 过滤规则

工具栏「过滤规则」（英文 Filters）打开独立窗口，不挡住主窗口，设备列表仍可操作。窗口内可添加、编辑、删除和单独启用规则，并「保存」或「取消」。规则只影响列表显示，不会改动已扫描到的设备、热插拔比较、自动恢复或已记住的连接意图，也不会因为编辑规则而去绑定、解绑、附加或分离设备。默认没有规则，因此不会预先隐藏任何设备。任一已启用规则匹配即隐藏该设备；空规则不隐藏任何设备。可按设备描述包含（不区分大小写）、精确 VID:PID（十六进制，格式为 VID:PID）或精确 BUSID 来匹配，不是默认的正则表达式。保存后写入 `%APPDATA%\UsbipdTool\config.json` 的 `device_filter_rules`，下次启动仍有效；旧配置没有该键时视为空规则。取消或关闭窗口会丢弃本次未保存的修改。再次点击工具栏按钮会把已打开的窗口带到前面。页首会显示已隐藏数量，并可一键暂时显示全部（不写入配置），以免设备被藏起来找不到；可见列表为空时会区分「没有物理设备」和「全部被规则隐藏」。操作按钮按设备自身的标识执行，不按过滤后的行号。

## 设置

工具栏「设置」打开标题为「设置」的独立窗口，**不针对某一台设备，也不会执行附加**，主窗口仍可操作。可配置：

- 是否使用 WSL 默认发行版（勾选时会只读显示检测到的默认名称，例如「使用默认发行版（Ubuntu）」）；取消勾选后可选择或手动输入发行版名称。程序启动时就会在后台只读枚举已安装的发行版和系统默认项（`wsl --list`，不会执行 `wsl --update` 或更改默认发行版），与 USB 扫描相互独立，也不占用 USB 忙碌锁、不阻塞一键附加。打开设置时直接使用已缓存的结果，并可在空闲时再轻量刷新，界面不会卡住。若尚未保存过有效的发行版名称，草稿会填入检测到的默认发行版；已保存且仍存在的选择会被保留。这些草稿在按下「确认」之前不会写入配置。加载中、未检测到发行版或读取失败时，设置页会如实提示。
- 新附加时是否默认加上 `--auto-attach`（本程序运行期间由该进程看管重插）。各设备自己的目标状态以最后一次成功的绑定 / 附加 / 分离 / 解绑为准，不会因为这项默认勾选而把已经分离或解绑的设备再自动附加回去。
- 可选的主机 IP（`--host-ip`）。留空则由 usbipd 自动检测（NAT 模式）。

设置窗口提供「确认」和「取消」，按钮组右缘与表单对齐。确认时会校验可选 IP 和发行版并保存；取消或关闭窗口会丢弃未保存的修改。再次点击工具栏按钮会把已打开的窗口带到前面。偏好保存在 `%APPDATA%\UsbipdTool\config.json`。`use_default_wsl_distro` 与已记住的发行版名称 `last_wsl_distro` 分开保存：勾选「使用默认发行版」并保存时，不会清空已记住的名称。旧配置没有 `use_default_wsl_distro` 时，视为使用默认发行版。

其它会立即保存的选项：界面语言、主题（浅色 / 深色 / 跟随系统）、「强制绑定」默认值。
